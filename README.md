# 🎮 Video Game Sales Prediction using Machine Learning

This project focuses on analyzing and predicting video game sales performance using machine learning techniques. By leveraging real-world video game sales data, the project aims to identify patterns that distinguish high-selling games from others and evaluate the effectiveness of different ML models.

---

## 📌 Project Overview

The video game industry generates massive amounts of data related to sales, platforms, genres, and regional performance. In this project, machine learning models are applied to predict whether a video game will achieve high sales based on historical and market-related features.

This project was developed as an end-to-end machine learning pipeline, covering data preprocessing, exploratory analysis, model training, evaluation, and result interpretation.

---

## 📊 Dataset

- Source: Video Game Sales Dataset (`vgsales.csv`)
- Features include:
  - Platform
  - Genre
  - Publisher
  - Regional sales (NA, EU, JP, Others)
  - Global sales

The dataset was cleaned and transformed to support supervised learning and classification tasks.

## 🤖 Machine Learning Models

The following models were implemented and compared:

- Random Forest Classifier
- XGBoost Classifier
- Multi-layer Perceptron (Neural Network)

Model performance was evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

XGBoost emerged as the best-performing model, providing strong predictive accuracy and balanced performance.
